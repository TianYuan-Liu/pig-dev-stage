# Paper insertion for R2.1 (Discussion: Limitations / Methods)

## For the Discussion "Limitations" paragraph (approx. 130 words)

Within each chronological stage bin the cohort is not balanced for breed,
sex or contributing BioProject. In our muscle data the dominant breed
fraction per stage ranges from 28 % (Pre-pubertal) to 62 % (Early childhood,
Duroc), and stage Adult is represented by only five samples of unknown
breed. A within-stage subgroup audit (Figure S8, Supplementary Table
`heterogeneity_stratification.csv`) shows that per-subgroup BA can deviate
from the marginal estimate: per-breed muscle BA spans 0.61 (Large white,
n=68) to 0.97 (Duroc, n=53), and a within-stage permutation test rejects
the chance-null for muscle/Sex (p=0.005), muscle/BioProject (p=0.014) and
liver/Breed (p=0.008). The classifier should therefore be interpreted as
calibrated to the breed/sex composition of pigGTEx; deployment to cohorts
dominated by under-represented breeds (e.g. exclusively Large white)
warrants re-calibration.

## For the Methods "Subgroup sensitivity analysis" (approx. 80 words)

To assess sensitivity to demographic heterogeneity within each chronological
stage, we replayed the same 5-fold stratified outer split used in the main
pipeline (seed = 42) and refitted each fold with the per-fold hyperparameters
stored alongside the published metrics, producing bit-identical CV
predictions. Balanced accuracy was then recomputed within each Breed, Sex
and BioProject level satisfying n>=10. Significance of the per-tissue
subgroup BA spread was assessed against a within-stage label permutation
null (1000 shuffles), preserving each subgroup's stage composition.
