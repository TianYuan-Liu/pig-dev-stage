## R3.2 (Reviewer 3, point 2)

> *"Details on Cross-Species Comparison: how were orthologous genes between pig and human defined? Was a strict one-to-one orthologue mapping used? Additionally, while the authors used |log2 FC| comparisons to avoid direct expression level comparisons, the pre-processing steps for the human dataset need to be more explicitly described to ensure reproducibility."*

**Response.** Yes, strict one-to-one orthologs are used, and every step is now made explicit. Pig (Sscrofa11.1) and human (GRCh38) Ensembl gene IDs were resolved to HGNC-style symbols via `mygene.info` (caches: `data/cardoso_moreira_2019/_pig_id_to_symbol.json` and `_human_id_to_symbol.json`). Candidate pairs were retained only where the gene symbol appears **exactly once** in each species' annotation (giving 15,200 candidates). Each candidate was then **verified against Ensembl Compara** via the public REST homology endpoint `/homology/id/sus_scrofa/{ENSSSCG_id}` with `target_species=human, type=orthologues`, retaining only pairs whose reciprocal classification was `ortholog_one2one` (the Compara confidence-1 equivalent). The result is **8,277 validated one-to-one orthologs** (54.5 % of the symbol-based candidates), cached at `review/analyses/results/pig_human_one_to_one_orthologs.csv`. All new cross-species analyses use this table.

The human Cardoso-Moreira preprocessing pipeline is now documented in full in the Methods (see `review/paper_inserts/R3.2.md`) and in the script docstring at `review/analyses/cross_species_all_tissues.py`. Briefly: (i) load `Human.RPKM.tsv` (derived from the E-MTAB-6814 deliverable `Human.RPKM.txt`); (ii) for each tissue, select columns whose header starts with `<Tissue>.`; (iii) discard prenatal columns (any stage ending in `wpc`); (iv) map Cardoso-Moreira postnatal stage labels to our 5-stage porcine scheme (Infant = newborn/infant/toddler; Pre-pubertal = school/youngTeenager; Post-pubertal = teenager/oldTeenager; Adult = youngAdult/youngMidAge/olderMidAge/senior); (v) compute log2 fold-change in raw RPKM space with a pseudocount of 0.01 (matching the pig TPM pipeline); (vi) test per-gene significance with Welch's *t*-test (more powerful at the small per-tissue postnatal n in this atlas — pig uses Mann-Whitney U because n is large); (vii) Benjamini-Hochberg FDR within the orthologue universe; (viii) the pre-specified strict filter (FDR < 0.10 + |log2FC| > 0.5 in both species, with a pig-anchored fallback for tissues where the small human n leaves human FDR underpowered).
