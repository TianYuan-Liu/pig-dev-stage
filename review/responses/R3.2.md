## R3.2 (Reviewer 3, point 2)

> *"Details on Cross-Species Comparison: how were orthologous genes between pig and human defined? Was a strict one-to-one orthologue mapping used? Additionally, while the authors used |log2 FC| comparisons to avoid direct expression level comparisons, the pre-processing steps for the human dataset need to be more explicitly described to ensure reproducibility."*

**Response.** Yes, a strict one-to-one ortholog mapping is used; we have now made every step explicit. Pig and human Ensembl gene identifiers were resolved to HGNC-style symbols via `mygene.info` (the resulting maps are cached in `data/cardoso_moreira_2019/_pig_id_to_symbol.json` and `_human_id_to_symbol.json`). We retained only symbols appearing **exactly once** in each species' annotation table ("shared-unique-symbol" filter), and then **verified** each candidate pair against the Ensembl Compara REST homology endpoint (`/homology/id/sus_scrofa/{ENSSSCG_id}` with `target_species=human`, `type=orthologues`), keeping only pairs whose reciprocal homology classification was `ortholog_one2one` (the Ensembl Compara confidence-1 equivalent). The full validated mapping (n pairs after filtering, see Supplementary Table S8) is cached at `review/analyses/results/pig_human_one_to_one_orthologs.csv` and used for all new cross-species analyses.

The human Cardoso-Moreira 2019 preprocessing pipeline is now documented in full in the Methods (R3.2 insert) and in the script docstring at `review/analyses/cross_species_all_tissues.py`. Briefly: (i) load `Human.RPKM.tsv` (derived from the `Human.RPKM.txt` deliverable in E-MTAB-6814); (ii) restrict to columns matching `<Tissue>.<stage>.<n>` for each tissue; (iii) drop any column whose stage label ends in `wpc` to retain postnatal samples only; (iv) map Cardoso-Moreira postnatal stage names to the porcine five-stage scheme (newborn/infant/toddler -> Infant; school/youngTeenager -> Pre-pubertal; teenager/oldTeenager -> Post-pubertal; youngAdult/youngMidAge -> Adult; olderMidAge/senior -> Adult); (v) compute log2 fold-change with a pseudocount of 0.01 in the raw RPKM space (matching the pig TPM pipeline) and apply Welch's t-test per gene (more powerful at the small per-tissue postnatal n in this atlas); (vi) Benjamini-Hochberg FDR correction; (vii) restrict the gene universe to the validated one-to-one ortholog set above. The pig pipeline is symmetric (TPM, Mann-Whitney U because n is large, identical FDR and one-to-one filter).
